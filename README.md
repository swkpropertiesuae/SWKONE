# SWK ONE

SWK ONE combines SWK Properties staff operations with AI and utilities. The complete application is prepared in the `SWK_ONE_Application.zip` delivery.

This repository has been initialized. Import the complete application by cloning this repository, extracting the ZIP, and copying the **contents** of the extracted `SWK_ONE` folder into the clone. Preserve the clone's `.git` directory. Commit and push the files to `main`.

Once imported, open `START_HERE.md` for local setup and the deployment plan.
